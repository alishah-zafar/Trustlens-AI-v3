# 🔍 TrustLens AI

### AI-Powered Scam & Fraud Detection Platform

TrustLens AI is an AI-powered security platform designed to help users identify potentially fraudulent and suspicious digital content before they fall victim to scams.

It analyzes messages, job offers, scholarship announcements, donation campaigns, investment opportunities, and other suspicious content and provides an easy-to-understand risk assessment.

---

## 🚨 The Problem

Online scams are becoming increasingly sophisticated.

Fraudulent messages can appear as legitimate:

* 💼 Job offers
* 🎓 Scholarship announcements
* 💰 Investment opportunities
* ❤️ Donation campaigns
* 📱 WhatsApp messages
* 🔗 Suspicious links
* 📧 Emails and other digital communications

Many users cannot easily determine whether the information they receive is genuine or fraudulent.

TrustLens AI aims to make scam detection simple and accessible.

---

## 💡 Our Solution

TrustLens AI uses Artificial Intelligence to analyze suspicious content and identify potential scam indicators.

Users can submit suspicious content, and the platform analyzes it to provide:

* 🛡️ Risk assessment
* 🚨 Scam detection
* 🔎 Suspicious indicators
* 📊 Risk level
* 💬 AI-generated explanation
* ✅ Recommended actions

The goal is to help users **think before they trust**.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd TrustLens-AI
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Configure environment variables

Create a `.env` file based on `.env.example`.

Example:

```env
GEMINI_API_KEY=your_api_key_here
OPENAI_API_KEY=your_api_key_here
```

**Never commit your real API keys to GitHub.**

The `.env` file should remain private.

### 4. Start the frontend

```bash
npm run dev
```

### 5. Start the backend

Open another terminal and run the backend according to the backend configuration.

For example:

```bash
cd backend
pip install -r requirements.txt
python app.py
```

---

## 🔐 Security

TrustLens AI is designed with basic security practices in mind.

Sensitive environment variables such as API keys are stored in `.env` files and excluded from Git using `.gitignore`.

Example:

```text
.env
.env.*
```

A `.env.example` file is provided so developers know which environment variables are required without exposing private credentials.

## 🧪 Example Use Case

A user receives a message:

> "Congratulations! You have been selected for a high-paying work-from-home job. Pay a small registration fee to receive your offer letter."

The user submits the message to TrustLens AI.

The system analyzes the content and may identify warning signs such as:

* Upfront payment request
* Unrealistic job claim
* Urgency
* Lack of verifiable company information

The platform then provides a risk assessment and explains why the message may be suspicious.
